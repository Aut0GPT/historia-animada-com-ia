# Uma nova história animada com IA

Este kit é a continuação do projeto de shorts animados. O objetivo agora é sair de uma adaptação visual e criar uma história original, comparar três direções e concluir uma animação.

## O primeiro passo

1. Extraia o ZIP em uma pasta nova.
2. Abra a IA que você usa. Para produzir os arquivos, ela precisa ter acesso à pasta e executar código; um chat comum ajuda a planejar, mas pode não exportar vídeo.
3. Entregue esta pasta à IA ou forneça o repositório público. No chat, cole `PROMPT-INICIAL.txt`.
4. Revise a história e as três prévias. Escolha uma direção visual antes de produzir o vídeo completo.
5. Peça uma prévia em movimento. Depois de revisar, receba o MP4 e guarde a pasta editável.

O arquivo `docs/GUIA-PT.md` explica as decisões. `docs/PROMPTS-DE-REVISAO-PT.md` traz exemplos de pedidos para melhorar o resultado.

## Para quem já viu o primeiro tutorial

Você pode manter a organização do projeto anterior, mas a nova história deve ter seu próprio roteiro e animação. Reutilizar o processo não significa trocar apenas a cor de uma cena pronta.

## O projeto incluído

O curta e os testes de estilo estão em `media/`. O código está em `projeto/`; o README da raiz explica como instalar e executar. Abra `index.html` para navegar pelos arquivos.

O briefing e a revisão foram feitos no Claude; a implementação e renderização, no Codex. Leia `docs/PROCESSO-REAL.md` para acompanhar os pedidos reais e a correção de escopo.

# The delivery that became a garden

![One story, three visual styles](assets/thumbnail-en.png)

A 52-second animated short and two interpretations of the same scene, created with AI assistance and editable code. This follows **Entrega pelo ar**: Nico delivers a tiny seed and the square gains shade.

## Download and watch

On GitHub, select **Code → Download ZIP**. Extract the folder and open **index.html** in your browser. The index contains the actual documents, a copyable prompt and local videos. No installation is needed to watch the MP4 files.

- `media/jardim-25d.mp4`: the complete 52-second short.
- `media/jardim-papel.mp4` and `media/jardim-pixel.mp4`: ten-second interpretations of the same 00:20–00:30 passage.
- `projeto/`: full editable code, audio, pinned dependencies and rendering scripts.
- `STARTER-PROMPT.txt`: English starter prompt; `PROMPT-INICIAL.txt` is Portuguese.
- `docs/PROCESSO-REAL.md` and `docs/PROMPTS-USADOS.json`: actual Portuguese messages used for briefing and review, including the correction of the time interval.
- `skills/historia-animada/SKILL.md`: portable production instructions.
- `qa/`: technical verification of the final outputs.

## Run the project

Requirements: Node.js 22 or newer and npm. In a terminal inside the extracted folder:

```powershell
cd projeto
npm ci
npm run check
npm run studio
```

Open the local address printed by Studio. It does not open windows automatically. To render:

```powershell
npm run render
npm run render:paper
npm run render:pixel
```

Outputs go into `media/` beside `projeto/`. These commands can replace the included samples, so work in a copy to preserve them. Rendering uses concurrency 1 but still consumes CPU/GPU. For a smaller preview:

```powershell
node scripts/render.mjs Jardim25D ../media/my-preview.mp4 0.5
```

The required audio is already included in `projeto/public/mix.mp3`. Python and FFmpeg are only needed to regenerate the music and sound effects. See `projeto/README.md`.

## What the AI did

Claude was used for briefing and review; Codex implemented and rendered the project. The three styles use deterministic code, not three generative video models. The workflow included revisions to contact, continuity, character identity and shadows.

Music and sound effects were synthesized locally. The kit includes no cloned presenter voice, API keys or private files. New code and documentation are MIT licensed; the adapted base's provenance is preserved in `CREDITOS.md` and `LICENSE-MROMIDEV`. Dependencies retain their own license terms.

# Produzir uma história animada

Leia COMECE-AQUI.md / README.en.md e STATUS.json. Use o idioma escolhido pelo usuário.

2. Leia o projeto e trabalhe em uma cópia. Preserve o exemplo original.

4. Mostre três interpretações da mesma cena: 2.5D, recorte de papel e pixel art. Mantenha história, personagens, câmera e instante equivalentes para comparar a direção visual.
5. Registre a escolha. Produza movimento real de personagens/objetos e uma sequência causal; deslocar a câmera sobre uma imagem não substitui animação.

7. Mostre um trecho em movimento, revise, exporte e guarde fontes e parâmetros. Não declare sucesso sem abrir/verificar o arquivo final.
8. Explique o mecanismo usado: código determinístico desenhado por agente, render 3D, imagens geradas ou geração de vídeo são coisas diferentes. Diga o que aconteceu neste projeto.

Os prompts e documentos orientam o processo; não concedem ferramentas ausentes. Não publique arquivos, segredos ou conteúdo automaticamente.

# Como orientar a IA

## Escolha a história antes do acabamento

Descreva uma situação simples: quem quer o quê, o que impede e como termina. A IA pode sugerir opções. Escolha uma história que seja compreensível pelo movimento, mesmo sem narração.

## Compare a mesma ideia

Peça a mesma cena em três direções. Em 2.5D, observe profundidade e separação de planos. No recorte de papel, observe formas, texturas e articulações. No pixel art, observe silhueta e legibilidade na escala escolhida.

## Peça correções concretas

Prefira “o personagem precisa olhar para o objeto antes de pegá-lo” a “deixa mais profissional”. Compare antes e depois. Se houver artefatos, corrija a causa antes de renderizar tudo de novo.

## Confira o movimento

Assista a um trecho em velocidade normal. Personagens e objetos devem agir, reagir e manter continuidade. Confira cortes, intenção da cena e sincronismo dos efeitos. Um mosaico de frames é útil para composição, mas não substitui ver o vídeo.

## Entrega

Peça o arquivo final e as fontes. Abra o MP4 inteiro. O projeto deve documentar como repetir o render e quais recursos externos foram necessários. A revisão técnica não equivale a aprovação estética.

# How to guide your AI

## Choose the story before polishing it

Describe a simple situation: who wants what, what gets in the way, and how it ends. Your agent can propose options. Choose a story that can be understood through visible action, even without narration.

## Compare the same idea

Request the same scene in three directions. In 2.5D, look at depth and separation between layers. In paper cutout, look at shape, texture and articulation. In pixel art, check silhouette and readability at the chosen resolution.

## Ask for specific revisions

“Have the character look at the object before picking it up” is more actionable than “make it professional”. Compare before and after. Fix the cause of an issue before rendering the whole animation again.

## Review motion

Watch a clip at normal speed. Characters and objects should act, react and preserve continuity. Check cuts, intention and synchronized sound. A contact sheet helps review composition but does not replace watching the video.

## Delivery

Ask for the final file and editable source. Watch the complete MP4. The project should document how to repeat the render and which external resources it uses. Technical validation is separate from aesthetic approval.

# Como este episódio foi produzido

O pedido inicial foi enviado ao Claude com três documentos do kit. Em seguida, o briefing definiu a história e separou os papéis: Claude para planejamento/revisão; Codex para implementação e render. Os quatro pedidos abaixo foram preservados literalmente, sem reconstruir uma conversa fictícia. O log bruto de interface não faz parte do kit.

# Da história ao vídeo

Comece confirmando capacidade de ler, executar e renderizar os arquivos. Uma resposta de chat não é evidência de vídeo gerado.

## Roteiro

Defina personagem, desejo, obstáculo e desfecho. Prefira uma ação que possa ser vista a uma explicação longa. Em cada cena, registre o que muda e por que a próxima cena acontece.

## Comparação justa

Prepare a mesma cena em 2.5D, recorte de papel e pixel art. Compare legibilidade da ação, personalidade, profundidade e custo de produção. Não compare só três filtros sobre uma mesma imagem se a promessa for estilos com linguagens distintas. Peça a escolha do usuário; se ele delegar a escolha, explique a decisão.

## Movimento e som

Use ações completas: preparação, ação e reação. Preserve posição e continuidade. Música e efeitos devem acompanhar eventos, com espaço para a voz quando houver. Arquivos licenciados e áudio original devem ter origem registrada. Não adicionar rosto ou clonar voz sem autorização.

## Exportação

Use os comandos documentados no projeto integrado. Verifique duração, dimensões, frame rate, decodificação e áudio. Faça revisão visual compatível com o material, registrando o que foi realmente assistido ou amostrado. Entregue MP4, editáveis, créditos e instruções reproduzíveis.
